# 🎬 Netflix Data Analysis Project

## 📌 Overview

This project explores and analyzes Netflix Movies and TV Shows data using Python and Data Analysis techniques. The goal of this project is to understand content trends, genre distribution, release patterns, and insights from Netflix’s catalog.

The project includes data cleaning, exploratory data analysis (EDA), visualizations, and key business insights derived from the dataset.

---

# 📂 Dataset Information

* **Dataset Name:** Netflix Titles Dataset
* **File Used:** `netflix_titles.csv`
* **Source:** Kaggle / Public Netflix Dataset

### Dataset Features

The dataset contains information such as:

* Show ID
* Title
* Director
* Cast
* Country
* Date Added
* Release Year
* Rating
* Duration
* Genre (Listed In)
* Description
* Type (Movie / TV Show)

# 📈 Key Insights

Some important findings from the analysis:

* Movies dominate Netflix content compared to TV Shows.
* Netflix experienced major content growth after 2015.
* Drama and International content are among the most common genres.
* The United States contributes the highest amount of content.
* TV-MA is one of the most frequent ratings.
